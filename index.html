银行流水关联匹配

需求规格 · 出纳模块 · 2026-10-16

1. 背景与目标

银行间转账会在转出方和转入方各产生一条流水，导入后彼此独立、分别生成凭证，导致财务账重复。

目标：保存或导入流水后，系统自动识别同一笔转账的两条流水并标记关联，避免重复记账。

2. 匹配条件

两条流水同时满足以下条件即判定为关联：

#条件说明
1金额相等金额绝对值完全一致
2方向相反一条收入，一条支出
3账号交叉A的对方账号 = B的账户账号，且B的对方账号 = A的账户账号
4日期相同日期为同一天
5暂未关联该银行流水暂未与其他账户银行流水关联

已关联的流水不参与后续匹配。

3. 匹配流程

多笔消歧

#条件处理
1双方均有时间（时分秒）按时间最相近匹配
2任一方无时间按【摘要】【备注】关键字匹配度择优
3以上均无法确定按先后顺序匹配第一笔

4. 示例

匹配在流水保存或导入完成后自动触发。

账户账户账号
工行22243100082619201002224
招行89213100082129024548921

工行2224 流水：

日期收入支出对方账号
2026-07-24202,000.00…8921

招行8921 流水：

日期收入支出对方账号
2026-07-24202,000.00…2224

金额 202,000 = 202,000 ✓   方向 支出↔收入 ✓   账号交叉 ✓   同日 ✓   → 自动关联

5. 边界场景

场景处理
对方账号缺失不满足账号交叉，不自动匹配
已关联流水被删除对手流水自动回退为未关联
跨日到账日期不同不匹配
